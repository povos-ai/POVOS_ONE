# UI Principles

## Every screen must be:

- Clean
- Consistent
- Fast
- Mobile Friendly
- Accessible

---

## Components

Buttons

Cards

Inputs

Tables

Navigation

Sidebar

Dashboard

Forms

Charts

AI Widgets

---

## Rules

Use 8px spacing system.

Avoid unnecessary colors.

Never overload the interface.

Prioritize readability.

Design for both desktop and mobile.

Maintain visual consistency.
