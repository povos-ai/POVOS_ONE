# Development Constitution

## Rule 1

Every screen must contain AI assistance.

AI is not a chatbot.

AI is the operating layer of the platform.

---

## Rule 2

Triple Review before every new feature.

1. Functional Review

2. Architecture Review

3. Enterprise Review

Only after approval will development continue.

---

## Rule 3

Never use quick fixes.

Always build scalable solutions.

---

## Rule 4

Every component must be reusable.

---

## Rule 5

Every feature must support future expansion.

No architecture should block future modules.

---

## Rule 6

Use Complete File Replacement whenever practical.

Avoid fragmented code snippets.
