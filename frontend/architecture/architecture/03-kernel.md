# Purpose

The Platform Kernel is the permanent core of <PovosText className="text-2xl" />.

It provides the foundational services that every capability, framework, module, and extension depends upon.

Business modules must never modify the Platform Kernel directly.

---

# Platform Kernel Responsibilities

- Identity Management
- Authentication
- Authorization
- Multi-Tenant Management
- Settings Management
- Module Registry
- Capability Registry
- Extension Registry
- Event Bus
- Workflow Engine
- Search Engine
- Notification Engine
- File Management
- Audit Logging
- Scheduler
- API Gateway
- AI Core
- Localization
- Configuration

---

# Kernel Design Principles

1. Stable
2. Modular
3. Secure
4. Observable
5. Event Driven
6. API First
7. Backward Compatible

---

# Kernel Rule

The Platform Kernel contains platform infrastructure only.

Business logic belongs to Business Modules.
